## Key files

### `src/data/site.js`
All brand facts in one place. Edit here — never in components.  
- `site.whatsapp.number` — `2349019624520`
- `site.recentOrders` — array is empty; add real orders here for the "just ordered" toast
- `site.heroVideo` — points to `assets/bmp/video/bmp-hero` (.mp4 + .webm + -poster.webp)
- `site.announcement` — the top announcement bar text

### `content/products.json`
Master product list. Fields per item:
```json
{
  "id": "bmp-lg-1",
  "title": "BMP LG 1",
  "price": 40000,
  "category": "gowns",
  "occasion": "event-ready",
  "colours": ["black"],
  "media": ["bmp/bmp-lg-1"]
}
```
Categories: `gowns`, `tops`, `sets`, `skirts`, `jumpsuits`  
Occasions: `event-ready`, `main-character`, `sunday-best`, `dinner-date`, `weekend`, `everyday-chic`  
After editing, run `python scripts/build_media.py` then `npm run build`.

### `src/data/sizes.js`
Owner-supplied UK 8–22 size chart (bust/waist/hip in inches).  
`recommendSize({bust, waist, hip}, fit)` → `{size, per, spread, decidedBy, custom, belowChart}`  
`saveMySize()` / `loadMySize()` — localStorage key `bmp.size`, fires `window['bmp:size']` event.

### `src/data/catalog.json`
Auto-generated. DO NOT hand-edit. Run `build_media.py` to regenerate.

## Find My Size (LIVE as of 2026-09-19)

Route: `/size-guide`  
Component: `src/pages/SizeGuide.jsx`  
Finder: `src/components/SizeFinder.jsx` — also opens inline on every product page  
Styles: `src/components/size.css`

**User flow:**
1. Visitor enters bust / waist / hip in inches or cm (any one is enough)
2. Chooses fitted or relaxed fit preference
3. Gets instant BMP size recommendation
4. Clicks "Save size N" → stored in localStorage, auto-selected on every product
5. Customers above size 22 → directed to WhatsApp with their measurements

**"Not sure? Find my size" link** appears below size chips on every chart-based product. Opens a centre drawer modal. "Use size N" pre-selects that size and closes the drawer.

## BMP Mirror — Virtual Try-On (NOT YET BUILT)

The MediaPipe WASM files are staged in `public/mirror/`. The concept and architecture are designed. This is the next major feature.

### What's ready
- `public/mirror/pose_landmarker_lite.task` — body landmark model (5.8 MB)
- `public/mirror/vision_wasm_internal.js + .wasm` — MediaPipe WASM
- `public/mirror/vision_wasm_nosimd_internal.js + .wasm` — fallback for no-SIMD browsers
- 4 test cut-outs in `media-originals/mirror-test/` using `rembg isnet-general-use` model:
  - `30kl-isnet-general-use.png` — cobalt gown (clean)
  - `80k-isnet-general-use.png` — red bodycon (clean)
  - `35op-isnet-general-use.png` — floral skirt set (clean)
  - `30ke-isnet-general-use.png` — light blue halter (semi-transparent areas, acceptable)

### What needs to be built
**1. Garment cut-outs** (`scripts/remove_bg.py` or manual)
- Run `rembg i -m isnet-general-use INPUT.jpg OUTPUT.png` for every front-facing mannequin photo
- Save as `media-originals/mirror-test/<slug>-isnet-general-use.png`
- Copy to `public/assets/bmp/cutouts/<slug>.png`

**2. `src/components/BmpMirror.jsx`**
```jsx
// Rough architecture:
// - <video> element (rear camera preferred, fallback front)
// - MediaPipe PoseLandmarker (WASM from /bmpclothing/mirror/)
//   → wasmFilePath: '/bmpclothing/mirror/vision_wasm_internal.wasm'
// - On each frame: detect shoulder/hip landmarks
// - Draw to <canvas> behind the video:
//   - Scale garment PNG from shoulder-to-shoulder width
//   - Position top of garment at shoulder Y
//   - Clip/warp to hip landmarks for a rough drape
// - Colour swap: canvas filter: hue-rotate(Xdeg) (for solid colour garments)
// - "Save my look" button: canvas.toBlob → link.download (branded export)
// - "Order this look" button: waLink() with garment details
```

**3. Integration points**
- Add "Try it on" button to `src/components/ProductBar.jsx`
- Gate it: `product.hasCutout === true` (add field to `content/products.json`)
- Route: either modal or `/mirror/:slug`
- Don't try to warp the garment (too complex for a phone) — overlay + scale is enough

**4. MediaPipe initialisation**
```js
import { PoseLandmarker, FilesetResolver } from '@mediapipe/tasks-vision'

const vision = await FilesetResolver.forVisionTasks('/bmpclothing/mirror/')
const landmarker = await PoseLandmarker.createFromOptions(vision, {
  baseOptions: { modelAssetPath: '/bmpclothing/mirror/pose_landmarker_lite.task' },
  runningMode: 'VIDEO',
  numPoses: 1,
})
```

**Package already installed:** `@mediapipe/tasks-vision@1.0.1` is in `package.json`.

## Adding a new product

1. Add photos to `media-originals/new/` (JPG, any size)
2. Add entry to `content/products.json` with a new ID, price, category, occasion
3. Run: `python scripts/build_media.py` — this generates WebP at 4 sizes, updates `catalog.json`
4. Run: `npm run build`
5. `git add . && git commit -m "Add [product name]" && git push`

Price naming convention used in filenames: `20k` = ₦20,000, `35op` = ₦35,000 "op" brand
